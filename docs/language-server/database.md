# database.ts：类型与符号数据库

源码：[language-server/src/database.ts](../../language-server/src/database.ts)。提供补全、类型推导、导航、继承和 API 文档共同使用的内存模型。

## 数据模型

| 类型 | 职责 |
| --- | --- |
| `DBType` | 类/struct/enum/delegate/event/primitive、继承、模板、成员、源位置 |
| `DBNamespace` / `DBNamespaceDeclaration` | 多次声明的命名空间、子命名空间、全局符号与声明来源 |
| `DBMethod` / `DBArg` | 参数/返回类型、重载 ID、const/property/mixin/event、宏元数据、delegate 绑定 |
| `DBProperty` | 字段类型、访问/编辑权限、UPROPERTY、来源与文档 |
| `DBAccessSpecifier` | 自定义访问列表、读/写/edit 权限 |
| `DBAuxiliarySymbol` | 与生成 API 关联的其他符号，供引用查找使用 |

`declaredModule` 区分脚本声明与原生 API；`isAutoGenerated` 是静态合成成员的重要标志。源 offset 供跳转/重命名使用，不是可有可无的装饰字段。

## 查询与缓存

- `LookupType(namespace, typename)`：作用域感知、限定名、模板实例化。新增语义优先用它，不要全部退化成 `GetTypeByName`。
- `LookupNamespace`、`LookupGlobalSymbol`、`LookupGlobalSymbolsWithPrefix`：名称/前缀查询。
- type/namespace 的 `findSymbols`、`findFirstSymbol`、`forEachSymbol`：成员及继承查询，支持 `DBAllowSymbol` 过滤函数/属性/类型/mixin。
- `CleanTypeName` / `TransferTypeQualifiers`：处理 const/ref，不要手写不同版本的清洗规则。
- `AddTypeToDatabase` / `RemoveTypeFromDatabase` / `OnDirtyTypeCaches` 维护 TypesById、TypesByName 和类型缓存；`addSymbol` 维护成员和前缀索引。

修改对象身份、继承或模板时测试缓存失效。重载不能单纯用方法名作唯一键。

## Unreal JSON 导入

`AddTypesFromUnreal` 逐项处理类型；下面是从 `fromJSON` 消费字段整理的**最小模型示例**，不是引擎所有字段的完整 schema：

```json
{
  "UExample": {
    "inherits": "UObject",
    "properties": {
      "Score": ["int", "分数说明", 0]
    },
    "methods": {
      "GetScore_0": {
        "name": "GetScore",
        "return": "int",
        "args": [],
        "const": true,
        "isProperty": true,
        "doc": "取得分数"
      }
    }
  }
}
```

- property 数组首项是类型；后续 string 为说明/历史 NoEdit、EditOnly 标记，number 为 flags（1 NoEdit、2 EditOnly、4 Protected）。
- method `args` 项使用 `name` / `type` / 可选 `default`，不是 DBArg 内部的 `typename` 字段名。
- `inherits` 进入 `supertype`；JSON `supertype` 进入 `unrealsuper`，两者不能混淆。
- `__Namespace` 类型键通常转命名空间；isEnum 的 `__` 前缀被剥掉后仍作为类型。
- `templateSpecialization`、`subtypes` 和模板协变/继承标记影响实例化。
- `meta` 的 key 转小写；delegate 绑定可由元数据或已知 Bind/Execute/Broadcast 方法识别。

`FinishTypesFromUnreal` 标记就绪，并注解 System timer delegate 绑定、FLinearColor 构造与 MakeFromHex。`AddPrimitiveTypes(floatIsFloat64)` 建立 float/double/int 等别名；调用由 server 完成类型接收时编排。

## 扩展指南

- 新原生 API 优先让 Unreal 导出数据库，再补充本文件对新字段的消费，不要只硬编码一条补全候选。
- 新返回类型推导规则可扩展 `determinesOutputTypeArgumentIndex` 等模型及 parser 消费链。
- 新分类同时检查 DBTypeClassification 和 semantic token 映射。
- 新生成方法用 [generated_code](generated_code.md) 模拟；不要假装是可重命名的真实源码声明。
- 针对 JSON 兼容性、同名不同 namespace、重载、模板特化、删除重建、原生/脚本同名准备 fixture。
